title: Booking consultations without leaving the website
client: Virtual Assistant Talent (US)
summary: A two-step consultation booking built into the website and synced to GoHighLevel.
role: Website developer since 2014; built the booking integration
stack: [WordPress, Elementor Pro, PHP, JavaScript, GoHighLevel API]
problem: Virtual Assistant Talent wanted visitors to book a free consultation on their own website, while still using GoHighLevel's calendar, confirmations and follow-up automations behind the scenes.
approach: I built a two-step booking flow inside Elementor. Step one is a form whose questions change with the type of consultation. Step two shows live open times from the GoHighLevel calendar. A small PHP backend talks to the GoHighLevel API, so the API key never reaches the browser, and the whole flow runs without page reloads.
result: Visitors book in two steps without leaving the site, and every booking lands in GoHighLevel with its confirmation and follow-up automations already running.
